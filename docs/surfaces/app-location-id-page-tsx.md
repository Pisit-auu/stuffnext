# หน้าห้อง (Operate)

ขอบเขต: `/location/[id]` และหน้าพี่น้องที่ใช้โครงเดียวกัน — `/home`, `/allasset`, `/allasset/[id]`,
`/profile/history`, `/admin/*`

โหมด: **Operate** — ผู้ใช้มาที่นี่เพื่อทำงานให้เสร็จ ไม่ได้มาอ่านหรือมาถูกโน้มน้าว

## ผู้ใช้และงาน
เจ้าหน้าที่พัสดุ/ธุรการ และครูที่มายืมของ งานคือ ตอบให้ได้ว่า "ของอยู่ห้องไหน เหลือกี่ชิ้น ใครถืออยู่"
แล้วเปิด-ปิดรายการยืมให้จบ ใช้งานสลับกันครึ่งหนึ่งบนมือถือ ครึ่งหนึ่งบนคอมพิวเตอร์

## สถานะที่ต้องมีครบทุกหน้า
กำลังโหลด (โครงตาราง) · ว่างเพราะยังไม่มีข้อมูล · ว่างเพราะตัวกรองไม่ตรง (ต้องมีปุ่มล้างตัวกรอง) ·
ผิดพลาดพร้อมปุ่มลองใหม่ · ยืนยันก่อนลบทุกครั้งพร้อมบอกผลข้างเคียง · แจ้งผลด้วย toast ไม่ใช่ alert()

## กฎที่ห้ามแหก
- ยอดที่แสดง = ยอดในฐานข้อมูล ลบด้วยของที่ถูกยืมออกและยังไม่คืน ตัวเลขต้องตรงเสมอ
- ปุ่มยืมใช้สีส้ม เพราะส้มคือความหมาย "ถูกยืมออก" ไม่ใช่เพราะเป็นปุ่มหลัก
- ทุกแถวมีแถบรหัส mono ริมซ้าย และยุบเป็นแผ่นป้ายบนจอแคบโดยรหัสยังอ่านออก
- ทุกหน้าที่มีตารางต้องมีปุ่มดาวน์โหลด Excel เพราะโรงเรียนใช้ไฟล์นี้ทำรายงานต่อ

## จังหวะที่จำได้
ลิ้นชักยืม — เลื่อนขึ้นตามแกนเดียว บอกยอดที่เหลือก่อนให้กรอก และห้ามยืมเกินยอดที่เหลือ

## ยังไม่ตัดสินใจ
การค้นหาในหน้าผู้ใช้งาน (`/admin/user`) ยังค้นเฉพาะหน้าปัจจุบัน เพราะ API แบ่งหน้าฝั่งเซิร์ฟเวอร์
ถ้าจะให้ค้นทั้งระบบต้องแก้ API ก่อน
