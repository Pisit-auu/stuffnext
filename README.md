# Project Name 
StuffNext
## Description 

This is a fullstack web application built with Next.js, Tailwind CSS, and PostgreSQL. เป็นเว็บไซต์ สำหรับจัดการครุภัณฑ์ รองรับ ผู้ใช้สามารถ ยืม คืน ครุภัณฑ์ จาก ห้องนี้ไปห้องอื่นได้ เก็บ ประวัติการยืมของผู้ใช้ แอดมิน สามารถ เพิ่ม ลบ แก้ไข สถานที่ต่างๆ และครุภัณฑ์ได้ แอดมิน สามารถ เพิ่มของในห้องได้ แอดมิน สามารถ สร้าง ลบ แก้ไข บัญชีผู้ใช้ได้ สามารถโหลดข้อมูลออกมาเป็นไฟล์ Excel ได้ สามารถค้นหา ครุภัณฑ์ได้ 

## Tech Stack 
- Next.js 
- Tailwind CSS 
- Prisma 
- PostgreSQL
